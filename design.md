# The Global Pulse observation system

Hallmark v2.0.0, app scope, existing brand. Keep NASA Earth imagery, real borders, green births, red deaths, blue net growth and amber replay. This is a scientific visualization, not a marketing page.

Controls use solid blue-charcoal surfaces, 12px panel corners, restrained dividers, tabular numerals and readable secondary ink. The Earth stays the focal object; its rendering and atmospheric physics remain unchanged. The observation ledger has a 316px desktop rail; the selected-country panel remains on the right. Mobile retains the existing collapsible ledger with explicit space for the timeline. No component trees or routes are replaced.

Every language, pause/replay, sound control, source disclosure and country action stays. Existing failure handling and simulation/data-engine contracts remain unchanged. Color and font values are declared as CSS tokens. Reduced motion and keyboard focus apply to all controls. Live denotes a running statistical simulation, not a feed of individual births/deaths; existing methodology remains accessible.
